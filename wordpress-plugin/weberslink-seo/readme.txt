== Description ==

**Weberslink SEO Toolkit** covers the on-page basics without the bloat.

**Write better pages**
* Focus keyword checks: in the title, description, URL, introduction and subheadings, plus keyword density
* Title and description length, content length, image alt text, internal and outbound links
* Readability: Flesch reading ease, long sentences, paragraph length, subheadings
* Live Google result preview with character counts, updated as you type

**Control the output**
* Title and description templates for posts, pages, categories, authors, search and 404 with variables (%title% %sitename% %sep% %excerpt% %term% %author% %category% %date% %page%)
* Per-page SEO title, description, canonical URL, social image, noindex and nofollow
* Open Graph and Twitter cards with a default image
* JSON-LD: WebSite with search, Organization or Person, WebPage, Article and breadcrumbs
* Hide search, date and author archives; keep noindex pages out of the WordPress sitemap
* Sitemap line and your own rules in robots.txt; Google, Bing, Yandex and Pinterest verification

**See the gaps**
* SEO audit: pages with no meta description or focus keyword, with one-click links to fix them

== Installation ==

1. Upload the `weberslink-seo` folder to `/wp-content/plugins/` and activate (deactivate any other SEO plugin first).
2. Open **SEO → Settings** and set your templates and organization details.
3. Edit a post or page and fill in the **SEO** box.

== Frequently Asked Questions ==

= Can I use it with Yoast or Rank Math? =
Use one SEO plugin at a time; both would print titles, descriptions and schema.

= Are my existing SEO titles imported? =
Not in this version. It stores its own fields.
