What's inside

  • Smaller files, same look: Compresses JPEG, PNG and WebP uploads and every generated thumbnail at the quality you choose. It never makes a file bigger, skips files already at your quality so repeat runs cannot degrade them, and keeps PNG transparency.
  • Scales huge photos: Camera originals of 4000 pixels and more are scaled down to the maximum you set. Generated thumbnails keep their sizes, and WordPress's own unscaled copy is compressed too.
  • Upright and private: Phone photos are turned upright and camera metadata such as GPS location is removed, so a picture can no longer reveal where it was taken.
  • WebP without server rules: Creates a WebP twin of each image and wraps images in a picture tag, so every browser picks the best format. It needs no .htaccess changes and is safe with page caches and CDNs.
  • Your whole library: Optimise existing media in small steps with a progress bar, so it works on slow hosts too. See the savings per image in the media library, and optimise or restore any single image.
  • Safe and private: Originals can be kept for one-click restore. Everything runs on your server with PHP's GD library: no account, no API key and no image ever leaves your site.

Install in 3 steps

  1. Download the ZIP above.
  2. In WordPress go to Plugins → Add New → Upload Plugin, choose the ZIP, install and activate.
  3. Open Media → Image Optimizer, check the settings and click Optimise all images.

FAQ

Common questions.

Is Weberslink Image Optimizer free?

Yes. It is a free download under the GPL and works on as many of your own WordPress sites as you like.

Does it send my images to an outside service?

No. Everything runs on your own server using PHP's GD library. There is no account, no API key and no monthly image quota.

Will my images look worse?

PNG recompression is lossless. JPEG and WebP are compressed at the quality you choose; around 80 to 85 is normally indistinguishable from the original. Files already at that quality are skipped, so running it again never degrades them.

Can I get my original back?

Yes, when Keep originals is on. Restore original puts the uploaded file back and removes its WebP versions. Thumbnails stay optimised.

How does it serve WebP?

It wraps images in a picture tag with a WebP source, so each browser picks the best format. No server rules are needed and it is safe with caching plugins and CDNs. If a theme styles images in a way that conflicts, switch this option off and compression still works.

Which WordPress and PHP versions does it need?

WordPress 5.9 or newer and PHP 7.4 or newer, with the GD extension (WebP support is needed only for the WebP files).
